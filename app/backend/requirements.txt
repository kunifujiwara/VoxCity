# PLATEAU LOD2 mode requires the VoxCityGML package (separate repo):
#   pip install -e <path-to-VoxCityGML>   (https://github.com/kunifujiwara/VoxCityGML)
#
# It must be a build that supports *rotated* target rectangles, i.e. one whose
# grid_utils.GridParams carries the affine grid frame (origin_lon/origin_lat +
# the e_col_*/e_row_* basis vectors). That support landed after the 0.2.0
# version bump without another one, so pinning a version cannot express it —
# the backend probes for those fields instead and reports LOD2 unavailable
# without them (a pre-rotation build would silently grid a rotated rectangle
# as its axis-aligned bounding box). Update the checkout and reinstall if
# /api/health says the package predates rotation support.
